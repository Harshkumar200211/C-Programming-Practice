# Student Record Manager

**Goal:** Add a few student records and display the saved records in the current run.

**Concepts practised:** Add a few student records and display the saved records in the current run.

## Compile and run

From this project folder:

```bash
gcc -std=c11 -Wall -Wextra -o app main.c
./app
```

On Windows, run `app.exe` after compiling.

## Sample input

```text
1
Harsh 90
2
3
```

## Expected output includes

```text
Harsh : 90.0
```

## Learning tip

Read the code, predict the result, run it, then change the sample inputs. This is a beginner learning example, not a production application.
