# C Program Guide — Sample Inputs and Outputs

This guide provides a quick preview for all 110 numbered exercises. Open the linked source file to read the complete code. Inputs and output excerpts below are the same sample cases used by the automated smoke tests.

> A sample output excerpt demonstrates the expected behavior; it may omit prompts or other lines. Test different values yourself to understand the logic.

## How to use this guide

1. Read the program title and its source-file comment.
2. Enter the sample input, where one is required.
3. Compare the result with the expected output excerpt.
4. Change the input, predict the result, then run the program again.
