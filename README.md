## 🚀 Quick start

### 1. Install a C compiler

- **Windows:** Install GCC through MinGW-w64 or MSYS2, or use an IDE that includes a C compiler.
- **Linux:** Install GCC using your distribution's package manager.
- **macOS:** Install Apple's command-line developer tools or another C compiler.

### 2. Compile and run a program

From the repository root, compile the Hello World file:

```bash
gcc -std=c11 -Wall -Wextra 01_Basics/001_hello_world.c -o hello
./hello
```

On Windows, run `hello.exe` after compiling. In an IDE, open the `.c` file, build it as a C program, and run it.

**Expected output**

```text
Hello, World!
```

### 3. Try an input-based example

Compile [004 — Sum of Two Numbers](01_Basics/004_sum_two_numbers.c), run it and enter:

```text
10 20
```

Expected output includes:

```text
Sum = 30
```

## ✅ Automated testing

GitHub Actions compiles every `.c` source file using GCC in C11 mode with warning flags. It also runs representative sample inputs against all 110 numbered programs and all 15 projects. A passing check means these sample runs worked; it is not a proof that every possible input is correct.

See [TESTING.md](TESTING.md) for local test instructions and limitations.

## 🎯 How to practise effectively

1. Read the problem title and understand what it asks you to calculate.
2. Before running the program, predict its output.
3. Compile the file and enter the sample input.
4. Change the values and observe how the result changes.
5. Explain each variable, condition and loop in your own words.
6. After finishing a level, try writing some programs again without looking at the solution.

## 📁 Repository notes

- Programs use standard C libraries; no external package installation is required.
- Compile each numbered file separately because each file has its own `main()`.
- Keep sample inputs small at first; several array examples support up to 100 elements.
- Pattern programs are exactly 10 examples, numbered 053–062.
- All 15 projects are console-based and are intended as learning examples, not production software.
